# 🔨 Apex Pro Handyman & Home Solutions

A high-converting, mobile-responsive corporate handyman and home repairs website built with **React**, **Vite**, and **Tailwind CSS**. 

The design system, color palette, and component structure are reverse-engineered directly from **600+ New Hampshire and New England home service contractor websites**.

---

## 🚀 Key Features

* **Authentic Corporate Color Scheme:** Built with regional trust colors: Deep Navy (`#002E5D`), Secondary Slate (`#2B5672`), and High-Contrast Safety Action Orange (`#D9480F`) for maximum lead conversion. Zero artificial neon shinings.
* **100% Mobile Responsive:** Optimized touch targets, responsive card grids (2 columns on mobile, 4 columns on desktop), compact typography, and a persistent **floating mobile bottom bar** with instant tap-to-call and quote triggers.
* **Interactive 3-Step Instant Estimate Calculator:** Homeowners can select service categories, project scopes, urgency, and input notes to get live price estimate ranges.
* **Built-in Local Database Engine (`localStorage`):** 
  * Lead submissions are stored persistently in browser storage.
  * Includes an **Internal Contractor Leads Portal (`/tracker`)** to review, search, filter, and update customer quote requests.
* **Interactive Before & After Project Gallery:** Touch-friendly and mouse-draggable comparison slider showing real craft transformations (trim, drywall, decks, plumbing fixtures).
* **Social Proof & Verified Reviews:** Google-style verified review cards with an interactive "Write a Review" form.
* **Local SEO Service Area Radius:** Searchable directory of Southern NH towns and ZIP codes with average dispatch times.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React 19 + Vite 8
* **Styling:** Tailwind CSS + Custom CSS Utilities
* **Icons:** Lucide React
* **Typography:** Google Fonts (`Oswald` for bold contractor headings, `Inter` for clean body copy)
* **Data Storage:** Client-side mock database with localStorage persistence

## 💻 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ecomwithdaud-hub/demo-handyman-website.git
   cd demo-handyman-website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
